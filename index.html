3. Generate the project

Next steps (do this after the zip downloads):
  1. Go to github.com/new and create an empty repository (do not initialize).
  2. Unzip the downloaded file on your PC.
  3. Push it to the repo: git init && git add . && git commit -m "init" && git push
  4. Open the repo → Actions tab → the Build APK workflow runs automatically.
  5. When green ✅, click the run → download app-debug.apk from Artifacts.
  6. Transfer the APK to your phone and install (enable "Unknown sources").

Why the APK is built by GitHub, not by this page

Turning HTML into an APK requires the Android SDK and Gradle — a ~1 GB toolchain that cannot run inside a webpage. This page generates a complete project containing a GitHub Actions workflow. When you push it, GitHub's free build servers run Gradle and hand you back the finished APK. Same end result as WebIntoApp, but your build runs on GitHub's cloud, with your code, and no third-party service holds your app.
